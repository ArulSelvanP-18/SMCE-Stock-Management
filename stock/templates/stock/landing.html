About The Project

SMCE Stock Management System is a web application designed to manage the college's inventory efficiently. It allows authorized users to add, view, modify and track items across the college's blocks, floors and rooms.

The system maintains stock status, dead-stock records, searchable reports, data exports and room-wise inventory information while keeping the existing Block → Floor → Room structure.
